# YAAM 1.37.37 — Release Notes

**Tag:** `v1.37.37`  
**Title:** `YAAM 1.37.37: Upload privacy safeguards, active station filtering, and platform stability fixes`

---

YAAM 1.37.37 introduces positive ADIF field allowlists for online logbook uploads, granular Data Safety privacy controls, active station callsign filtering, and extensive platform and DSP fixes.

### Highlights

* **Positive Upload Allowlist (Patch 61):** Uploads to QRZ, eQSL, Club Log, HRDLog, HamQTH, Wavelog, and LoTW now use strict per-service allowlists. The other station's personal data (email, address, notes, biography, precise coordinates) and your own street address/exact coordinates are excluded by default.
* **Three Granular Privacy Opt-Ins:** Added configurable switches under **Settings → Data Safety**:
  1. *Upload other station's name and QTH* (default: OFF).
  2. *Upload contact details and precise locations* (default: OFF).
  3. *Upload comments and QSL messages* (default: OFF; internal tags are always stripped).
* **Active Station Callsign Boundary:** Online synchronization (QSL Hub Sync All / Selected, Wavelog full sync) now uploads only QSOs matching the active station's callsign. Historical or imported QSOs under other callsigns remain safe in the local log and are cleanly skipped with reported counts.
* **Wavelog Connection & Rights Test:** New non-mutating `check_auth` test distinguishes read-only from read/write API keys, warning before upload attempts fail. Modern endpoints (`api/qso`, `get_contacts_adif`, `station_info`) are now used.
* **Strict TQSL Verification:** Only exit code 0 marks an entire batch as uploaded. Diagnostic codes 8, 9, and 14 leave QSOs unmarked and present TQSL diagnostic messages for operator review. Temporary files are signed inside an isolated `0700` sandbox directory.
* **Digital Suite & DSP Improvements:**
  - Standardized PSK31 Varicode to the 128-character G3PLX specification, eliminating duplicate codes.
  - Corrected Hellschreiber fractional sample accumulator to achieve exact 245 pixels/s reception at 44.1 kHz and 48 kHz.
  - Buffered streaming RTTY/PSK characters to decode callsigns on complete word boundaries.
  - Inhibited unconfigured digital audio playback before PTT keying to prevent invalid RF transmission.
  - Applied calibrated +0.66 s DT timing offset to FT8 decodes and normalized weather queries to coarse 4-character grid locators.
* **Radio & CW Safety:**
  - 200 ms connection loss detection during CW transmission immediately cancels ON AIR status and Auto-CQ.
  - Connected `rigctld` instances default to the shared client without requiring Operator Desk to be opened first.
* **Hardening & Security:**
  - Removed `get-task-allow` debugger entitlement from Release builds and disabled base entitlement injection.
  - Documented full entitlement inventory in `DEVELOPER_DOCUMENTATION.md`.
  - Replaced silent ADIF auto-save failures (`try?`) with surfaced I/O error reporting and serialized disk writes.
  - Required explicit in-band frequencies for contest quick-logging.
  - Removed legacy demonstration callsigns and seed entries from club memberships, call history, and SCP engines.

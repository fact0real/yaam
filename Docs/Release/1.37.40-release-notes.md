# YAAM 1.37.40 (190) — local rigctld security hardening

- Bound the local rigctld emulator to 8 clients, 4096 bytes per command line, 64 KiB of pending responses and 256 commands per client per second. Misbehaving sessions are disconnected; normal clients remain available.
- Preserve partial TCP replies and release client sockets reliably during shutdown/restart.
- Keep the server restricted to loopback. No radio transmit behavior or entitlement is enabled by this update.
- Re-audit EA3JIC patch 61 and all supplied numbered open items against source and the shared board; verify existing upload privacy and distinguish incomplete hardware/protocol work from completed safety mitigations.

See [the audit](../../Reports/EA3JIC-20261019-email-audit.md) and shared-board [#269](https://github.com/fact0real/yaam-lab599-shared-board/issues/269). FT8 SNR/RR73, PSK symbol-clock recovery and native digital playback remain open; this version does not claim those fixes.

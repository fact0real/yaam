# YAAM 1.37.62 (212) — security hardening for HamClock kiosk remote control

- Authenticate all HamClock Remote Web Server endpoints (`/`, `/api/telemetry`, `/api/rotator`) using a secure, per-session authentication token (`?token=...` or `Authorization: Bearer`).
- Prevent unauthenticated and cross-origin antenna rotator movement: remove wildcard CORS (`Access-Control-Allow-Origin: *`) on mutating endpoints and strictly validate bearing azimuth inputs (`0°..360°`).
- Include the authentication token automatically inside the HamClock QR code and embedded kiosk dashboard script so authorized companion tablets connect seamlessly.
- Fix network connection state handling in `HamClockRemoteWebServer` to properly remove disconnected and cancelled client sockets from memory on disconnect.
- Retain all 1.37.61 logbook viewport performance enhancements, 1.37.60 DXCC identity reconciliations, and 1.37.59 QRZ Incoming follow-up features.

Validation: 4 focused security regression checks covering unauthenticated rejection, authenticated rotator/telemetry access, CORS header restriction, and socket disconnect cleanup; 2,800 column-geometry/coverage checks; full review regression test suite (Varicode, CW, FT8 DT calibration/expanded decoding); Debug and optimized Release builds; update policy and staged Release entitlement checks passed.

# YAAM 1.37.57 (207) — reviewed sync and radio evidence

This developer preview includes the signed Sparkle updater introduced in the website-only 1.37.56 preview, plus the following improvements:

- Digital Suite logging requires a fresh, physical radio frequency readback from the current connection. Driver defaults, optimistic tune commands and mode-only responses are excluded. Missing fields and manual frequency edits are explained in the confirmation form.
- Both QSL Hub Studio and Awards preview Sync All upload counts per service before queueing. Approval is bound to the reviewed station, log and QSO/provider pairs; changes require another review. Edited contacts stop later upload batches.
- Olivia/Contestia is explicitly experimental. Removed synthetic live decoding and callsign inference, blocked practice logging, and required manual review without invented reports or dial frequency. Native interoperable Olivia encoding/decoding is still unavailable.
- FT8 warnings now distinguish relative signal DT from unverified local clock accuracy. Removed the clock-changing shell command and linked Apple's clock-settings guidance. Independent time-reference acquisition and positive clock attribution remain future work.
- Generic Russia labels are reconciled with explicit ADIF DXCC identity for statistics and coverage while preserving European/Asiatic distinctions and historical fields. Ambiguous portable or conflicting identities remain for review.

## Download and update

macOS 15.6 or later, Apple Silicon (arm64). **This is an ad-hoc-signed, non-notarized developer preview**, not a Developer ID / Apple-notarized release. Sparkle verifies the publisher's Ed25519-signed feed and archive; that is distinct from Apple notarization. Version 1.37.56 users can use YAAM → Check for Updates. Older builds require one manual installation to obtain the updater. GPL-3.0 corresponding source is provided in GitHub and alongside the website download.

The known Digital Modem save/upload ordering issue and independent FT8 time-reference work are not fixed in this release. Stop active transmission and Auto-CQ before installing an update; software guards do not establish physical receive.

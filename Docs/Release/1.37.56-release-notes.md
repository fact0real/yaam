# YAAM 1.37.56 (206) — signed in-app software updates

- Replace the GitHub browser-only update check with Sparkle 2.10.1 and an HTTPS appcast hosted at `yaam.asis.sh`.
- Require Ed25519 signatures for the feed and archives, verify before extraction, and never expire a feed-signature failure into unsigned fallback. Signing keys remain in the publisher's Mac Keychain, separate from the web server.
- Restrict release archives to the exact YAAM origin/product/version naming, increasing numeric builds and bounded package size. Sparkle additionally evaluates platform compatibility and validates/installs the update.
- Add Software Updates under Settings → Safety & AI. Daily checks start enabled; automatic downloads/install-on-quit are opt-in. Keep manual Check for Updates, native progress, cancellation, release notes and installation UI.
- Defer requested relaunch while a registered transmitter or CW Auto-CQ is active. Preserve the existing ordinary quit handler and its CAT/PTT drain. No force-kill or quarantine-removal installer script is added.
- Document update network behavior, release signing and the one-time bootstrap from an older app.

This website preview is not Apple-notarized. Sparkle publisher signatures and macOS notarization serve different purposes. Older YAAM binaries require a one-time manual installation to obtain the new updater. The corresponding source archive accompanies the website binary.

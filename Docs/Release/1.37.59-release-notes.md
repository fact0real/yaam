# YAAM 1.37.59 (209) — reliable QRZ Incoming email selection

- Fix the empty bulk-email draft by presenting a nonempty recipient snapshot together with its sheet identity.
- Check published QRZ profile emails automatically, once per callsign; show progress, stop, retry and sign-in states.
- Select only requests needing details with a usable published QRZ email. Missing, failed and incomplete checks stay unchecked.
- Prepare one personalized message per callsign, combining its selected request dates. Retain send progress, stop-after-current and explicit follow-up control.
- Keep authenticated absence evidence separate from lookup failures. Provide a prefilled rejection for current requests without a published email and local archiving for retained cases.
- Stop subsequent deliveries after a station change and recheck successful email history before each message.
- Cache local review status while email checks progress; update English and Persian instructions.
- Includes the multi-file ADIF Live Sync support from local build 1.37.58 (208).

Validation: focused QRZ email regressions (82 checks), grouping/template regression, and macOS Debug/Release builds. Live visual review and actual QRZ/SMTP delivery were not completed; no live-provider acceptance is claimed.

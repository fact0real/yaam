# YAAM 1.37.61 (211) — smoother logbook scrolling

- Build cells only for pinned columns and the horizontal viewport, with neighbouring columns prepared for continuous gestures. Preserve exact column widths, header alignment, editing and row actions.
- Keep horizontal visibility state inside the scroll viewport so crossing a column boundary does not recalculate the toolbar and filter summaries.
- Read confirmation-ID sets and the opportunity index once per table update instead of repeatedly obtaining them for every row.
- Remove the 1,000-row display limit, growing-prefix copies and automatic footer loading. The scrollbar now represents the entire filtered log; rows remain vertically lazy.
- Retain the published 1.37.59 QRZ Incoming follow-up fixes.

Validation: 2,800 column-geometry/coverage checks; production row/viewport rendering with 100,000 invented contacts and 30 columns; deep jumps beyond row 1,000, end-of-log access, horizontal scrolling, compact/normal widths, light/dark, filtering/empty/restored collections, selection and editing state. Debug and optimized Release builds, update-policy and staged Release-entitlement checks passed.

In the same-Mac fixture comparison, initial cell construction fell from 1,380 to 552 and ten vertical jumps built 6,252 cells instead of 15,630 (60% fewer). Mean measured jump/layout time was 200 ms versus 383 ms (48% lower). These are fixture measurements, not a frame-rate guarantee or a live-station benchmark. No real logbook, credentials, network services or radio was used by the fixture.

macOS 15.6+, Apple Silicon. This ad-hoc-signed developer preview is not Apple-notarized. Publisher update signatures are separate from Apple notarization. The corresponding GPL source accompanies the release.

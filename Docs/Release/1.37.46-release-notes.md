# YAAM 1.37.46 (196)

Add **QSL Graylist** under **Operator Desk → QSL & Data** and the Tools menu. The active station’s complete master workspace lists exact callsigns with at least three distinct contacts and zero received confirmations. Duplicate imports do not increase counts, and the first recognized received QSL clears the automatic flag.

The searchable table and details show contact history, bands/modes, recorded submission evidence and incomplete data. Graylist badges in the callsign inspector and Quick Log open the workspace. Open contacts uses the exact callsign search in the existing Log Table.

Optional **Lower priority in Call Roster** (initially off) applies after at least three contacts pass the selected wait, default 90 days. The real roster and Apex suggestion update immediately, preserve direct-call priority and retain award-opportunity labels. Wait, enablement and per-callsign exceptions persist per station profile. Source checkpoints and incomplete/stale history remain visible; the feature uses local confirmation evidence.

Tracking: [Y-163 / shared board #421](https://github.com/fact0real/yaam-lab599-shared-board/issues/421). [Implementation and validation](../../Reports/20261024-QSL-graylist.md).

Local delivery uses the existing application entitlements and ad-hoc signature. The package is built from an isolated feature checkout, excluding unrelated uncommitted radio changes. No public binary release or updater-feed change is part of this delivery.

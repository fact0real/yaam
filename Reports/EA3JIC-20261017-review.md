## Privacy policy choices

All three Data Safety opt-ins start off: (1) other-station `NAME`/`QTH`; (2) contact details plus both stations' precise positions; (3) operator comments/QSL messages. `QSL_VIA` moved behind the contact opt-in because imported values can contain a postal route. `GRIDSQUARE`, `MY_GRIDSQUARE` and their grid lists are reduced to valid six-character locators by default; only an explicit contact-details opt-in preserves longer logbook-service grids. The LoTW allowlist always stays minimal and six-character-limited, regardless of opt-ins. TQSL can still sign its configured station location: this is not a promise to hide the operator's signing location from LoTW.

Field names are canonicalized to uppercase. Conflicting case variants are omitted deterministically. Empty values, unknown names, all `APP_*` and `*_INTL` never leave. Comments are stripped of YAAM tags when sharing is enabled; tags-only comments disappear. Local record dictionaries, database and manual exports are preserved. Changing a preference cannot retract an already dispatched network request.

TQSL signs a filtered copy in a private 0700 directory with a 0600 file, then removes the directory. Stale cleanup now removes only owned UUID-named private directories older than 24 hours; it never sweeps user ADIF/TQ8 files or live inputs in `.tqsl`. Input files and their existing `.tq8` companions are untouched. UTF-8 and legacy Latin-1 file input are accepted. Wavelog's required keyed discovery/auth URLs are kept out of error messages, disk caching and redirect forwarding. A recording test uses only invented keys and domains.

The author's 41/19/9 field counts came from an unavailable catcher and are not repeated as locally verified figures. Our stricter free-text/grid policy also changes the exact count for some records.

## Independent FT8 observations

Pinned dependency: `ft8-808` `efe779c6bab3c5ee7c359378614debfd14ae1e00`, unchanged. A synthesized FT8 waveform placed at 0.5/1.5/2.3/2.7 s into a 15-second input decoded at 0.64/1.68/2.48/2.88 s. After correction the resulting DT is within 0.1 s of 0/1/1.8/2.2 s. The regression also exercises the negative warning boundary and retains uncorrected FT4 timing.

With seeded white Gaussian noise and the 2500-Hz reference calculation, input SNR -20/-10/0/+15/+30 dB produced approximately -22.71/-12.80/-9.87/-9.17/-9.09 dB from the pinned estimator. This demonstrates compression; it does not validate a replacement estimator against WSJT-X.
